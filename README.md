# Mini Project - RevoU Coding Camp

Repository ini berisi tugas Mini Project untuk program **RevoU Coding Camp (Batch 24 Agustus 2026)** yang dikerjakan oleh **Rizqi Muchamad Anafis Tontowi**.

---

## 📌 Deskripsi Project
Project ini berfokus pada implementasi fundamental web development (HTML, CSS, dan JavaScript) untuk membangun antarmuka web yang responsif, terstruktur, dan memiliki logika interaktif.

## 🚀 Fitur Utama
* **Struktur Semantik:** Menggunakan elemen HTML5 terstruktur.
* **Tampilan Responsif:** Styling CSS3 yang menyesuaikan berbagai ukuran layar.
* **Logika Interaktif:** Manipulasi DOM dan validasi form menggunakan Vanilla JavaScript.

## 🛠️ Tech Stack
* **HTML5**
* **CSS3**
* **JavaScript (Vanilla JS)**
